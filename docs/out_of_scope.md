# Out-of-Scope Items (Milestone 3)

The following items are officially out of scope for this backend/API milestone. They represent future phases or dependencies handled by other teams:

1. **iOS App Development & Deployment:**
   - The native iOS codebase itself.
   - TestFlight builds and App Store submission (these are handled by your iOS developer).
   - Apple Developer Account verification delays.

2. **User Authentication & Profiles:**
   - Currently, rooms are tied to a `session_id`. Full user accounts (login, password resets, saving multiple rooms to a persistent user profile across devices) is a Phase 2 enhancement.

3. **E-Commerce / Affiliate Links:**
   - Automatically linking checklist items (e.g., "Warm White Paint") to purchasing links (e.g., Home Depot or Amazon) is a future enhancement.

4. **Web UI Styling Extravagance:**
   - The React web UI is a clean, functional beta designed to prove out the flow. Deeply customized 3D animations or complex transitions in the web app are not included, as the primary consumer facing product is the iOS app.
